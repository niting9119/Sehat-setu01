# 🏥 Sehat Setu — Developer Guide & Quick Reference

For full project instructions, see the root [`../README.md`](../README.md).

## Quick Launch:
- Double-click `run.bat` to launch the server and C++ terminal.
- Or run `node server.js` or `npm start`.
- Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Key Files:
- `server.js`: Node.js HTTP server & API endpoints.
- `js/state.js`: Central state store, mock data, and user accounts.
- `js/app.js`: Main UI views (Citizen, Doctor, ASHA, Admin).
- `js/router.js`: Hash router & portal permissions.
- `css/variables.css`: Theme colors, typography, and styling variables.
- `cpp/sehat_setu.cpp`: Standalone C++ surveillance engine.
